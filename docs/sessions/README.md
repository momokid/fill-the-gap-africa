# Session notes

One short note per working session: what changed, why, and what is still open.
These are **not** loaded automatically — `AGENTS.md` tells the agent to read the
newest one at the start of a session. That keeps the always-on context tiny
while still giving a durable record.

## Naming

`YYYY-MM-DD-<topic>.md`, for example `2026-10-27-page-content-and-move.md`.

## Template

```md
# <topic> — <date>

## Done
- …

## Decisions
- … (and why)

## Open
- …
```

## Rules

- 10–20 lines. Link to code paths instead of pasting them.
- Record decisions the code cannot express (trade-offs, rejected options).
- Do not repeat `AGENTS.md`; update that file when a rule changes.
